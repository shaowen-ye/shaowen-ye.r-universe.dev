# shaowen-ye R-universe registry

This repository registers the R packages published at
<https://shaowen-ye.r-universe.dev>.

Registered packages:

- [`SOMevidence`](https://github.com/shaowen-ye/SOMevidence)

## Publication policy

The registry follows the latest published GitHub Release of `SOMevidence` via
the `*release` reference. This keeps the R-universe package repository aligned
with documented stable versions.
